What this tool does not do

  • It reads configuration only. It never runs an agent, connects to a server or watches live traffic, so it cannot see what an agent actually does.
  • It cannot see what a platform does not export. Missing fields are reported as gaps, never as failures.
  • Tool capability comes from HTTP methods where the export has them, and otherwise from words in the tool's name. A name can be misleading, so unclear tools are marked unknown rather than assumed safe.
  • The Copilot Studio, Bedrock and Foundry files here hold synthetic values in each platform's real field names and response shapes. The real-world data covers MCP configs and the MCP Registry only.
  • Policy verification proves properties of the policy file as written. It does not prove that anything enforces it.
  • AIVSS is a v0.8 draft, and the spec calls some of its values provisional. Scores will move if the published method changes.
